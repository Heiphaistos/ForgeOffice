# @forgeoffice/formulas : état

Moteur de formules Excel en TypeScript pur, sans DOM.

## Fait et prouvé

- **505 fonctions** dans `src/functions/` : maths, statistiques et lois, texte (REGEX compris), dates (systèmes 1900 avec le 29/02/1900, et 1904), logique, LET/LAMBDA/MAP/REDUCE/SCAN/BYROW/BYCOL/MAKEARRAY, recherche (XLOOKUP, XMATCH, INDEX, OFFSET, INDIRECT...), tableaux dynamiques (FILTER, SORT, UNIQUE, SEQUENCE, TAKE, DROP, VSTACK, HSTACK, TOCOL, WRAPROWS, GROUPBY...), finances (VPM, VA, VC, NPM, TAUX, VAN, TRI, TRI.PAIEMENTS, TRIM, DB, DDB, VDB, coupons, PRIX.TITRE, RENDEMENT.TITRE, DUREE, bons du Trésor, escompte, PRICEMAT/YIELDMAT), information, ingénierie (bases, opérations bit à bit, ERF, Bessel J/I/K/Y, CONVERT, complexes), base de données (BDSOMME...). Fonctions volatiles marquées.
- Syntaxe canonique et française : `toLocalized` / `fromLocalized` (noms de fonctions, `;`, virgule décimale, VRAI/FAUX, erreurs #VALEUR! #NOM? #EPARS!...), préfixes `_xlfn.` des fichiers (`toFileFormula` / `fromFileFormula`).
- `FormulaEngine` (`src/engine/` : `workbook.ts` = la classe ; `types.ts` types publics et état interne ; `util.ts` utilitaires ; `context.ts` contexte d'évaluation + parcours de zones ; `structure.ts` décalage lignes/colonnes ; `adjust.ts`, `deps.ts`) : recalcul incrémental par graphe de dépendances (précédents relevés pendant l'évaluation, donc INDIRECT/DECALER suivis), débordement et #EPARS!, opérateur `A1#`, références circulaires (0 + liste) et calcul itératif, feuilles (ajout, renommage, suppression avec #REF!), noms (globaux, de feuille, LAMBDA nommées), tableaux structurés, insertion/suppression de lignes et colonnes avec #REF!, `translateFormula` (recopie), écouteurs, `batch`, références 3D, colonnes entières, chaînes de dépendances profondes sans dépassement de pile.
- Formats de nombre (`formatValue`) et saisie (`parseInput`) en fr-FR et en-US.

Tests : `node --test packages/formulas/tests/*.test.ts` : **927 tests, 927 réussis** (849 avant la session du 2026-11-04 ; +78) dont des centaines de valeurs relevées dans Excel 365 par COM. `npx tsc -p tsconfig.json --noEmit` : aucune erreur dans `packages/formulas`.

### Ajouts du 2026-11-04

- **Fonctions** (489 -> 505) : ACCRINT, AMORLINC, AMORDEGRC, ODDFPRICE/ODDFYIELD/ODDLPRICE/ODDLYIELD (`securities-odd.ts`, 313 valeurs identiques à Excel), PREVISION.ETS / .CONFINT / .CARACTERESAISONNIER / .STAT (`forecast-ets.ts`), PIVOTBY, GETPIVOTDATA, TRIMRANGE (`pivot.ts`), EUROCONVERT, BAHTTEXT (`extras.ts`, 60 valeurs identiques à Excel). WEBSERVICE, FILTERXML, STOCKHISTORY, RTD, IMAGE : refus volontaire (#NOM? comme Excel hors ligne).
- **Noms français** vérifiés dans Excel 365 : corrigés DCOUNT = BDNB, MIDB = STXTB, NOT = NON, VALUE = CNUM, SYD = SYD, RANDARRAY = TABLEAU.ALEA. Les noms de GROUPBY, PIVOTBY, PERCENTOF, ISOMITTED, REGEX* n'ont pu être vérifiés (absents de l'Excel installé) et restent ceux de la table.
- **CELLULE / INFORMATIONS complètes** : format (G, F2, ,0 / P0 en français, C2-, D1..D9 / H1..H4, P pourcentage -> %…), parentheses, couleur, contenu, nomfichier, prefixe (alignement), largeur, protege, type ('i' en français). Les styles viennent de l'application hôte (`EngineOptions.host` : `cellStyle`, `columnWidth`, `fileName`, `directory`, `osVersion`, `pivotValue`). CELLULE est maintenant volatile.
- **Références 3D** : `shiftFormula` ajuste une référence 3D seulement si toutes ses feuilles sont modifiées ensemble (`insertRows(feuille, at, n, groupe)`), comme Excel (vérifié par COM : une insertion sur une seule feuille ne change pas la formule) ; `removeSheetInFormula(formule, nom, ordreOnglets)` raccourcit `A:C!x` en `A:B!x` ou `B:C!x` quand une feuille de bord est supprimée (vérifié par COM), sans effet pour une feuille intermédiaire.
- **Dépendances de plages** : index d'intervalles (arbre de segments par colonne, `deps.ts`) pour les zones hautes, plus cache de statistiques de colonne (`aggregate.ts`) utilisé par SOMME / MOYENNE / NB sur les grandes zones. 100 000 totaux cumulés `SUM($A$1:A1)` : saisie + calcul ~0,9 s, recalcul complet ~0,3 s (test `range-index.test.ts`, seuils 6 s / 3 s car les fichiers de tests tournent en parallèle ; était quadratique : 20 000 lignes = 12 s).
- **Recalcul partiel** : ajout / renommage / suppression de feuille, définition ou suppression de nom, de tableau : seules les formules concernées (texte mentionnant la feuille, le nom ou le tableau, noms qui en dépendent, fonctions lisant la structure : INDIRECT, FEUILLE, CELLULE…) sont recalculées. Insertion / suppression de lignes et de colonnes : recalcul de toutes les formules des feuilles modifiées, de celles des autres feuilles qui les lisent (index de dépendances) et de celles dont le texte a été réécrit ; les autres feuilles gardent valeurs et dépendances. Raison du recalcul complet des feuilles modifiées : l'index de dépendances est indexé par position, il faudrait le remapper cellule par cellule (coût équivalent). Prouvé par un test différentiel (150 tirages x 5 opérations comparés au recalcul complet), qui a révélé et fait corriger un défaut préexistant (débordement d'une formule calculée pendant la lecture d'une zone).
- Correctif : une zone lue pendant un recalcul voit maintenant les cellules débordées par une formule calculée au même moment.

## Reste à faire / limites connues

- PREVISION.ETS : modèle ETS additif (Holt-Winters) avec optimiseur propre. Séries exactes (linéaires, saisonnières parfaites) : valeurs d'Excel à l'identique ; séries bruitées : écart d'environ 1 % sur les prévisions, 3 à 6 % sur l'intervalle de confiance, alpha / bêta / gamma différents. Détection de saisonnalité par autocorrélation (seuil 0,7) : peut différer d'Excel sur des séries courtes.
- ACCRINT avec calc_method = FALSE et règlement après first_interest : 7 cas sur 148 relevés s'écartent d'un jour d'intérêts ; tout le reste (TRUE, règlement avant first_interest, toutes bases et fréquences) est identique à Excel.
- EUROCONVERT : taux officiels des 12 monnaies de la zone euro d'origine ; Excel sans le complément « Euro Currency Tools » répond #NOM? (donc pas de valeurs d'Excel pour comparer). TRIMRANGE : absent de l'Excel installé, comportement d'après la documentation (zone entièrement vide -> #CALC!, hypothèse) ; syntaxe `A1.:.B5` non reconnue. PIVOTBY : version simplifiée (une colonne de valeurs, pas de relative_to).
- Le Tableur (`packages/excel`) doit transmettre `host` (styles de cellules, nom de fichier, tableaux croises) au moteur pour que CELLULE / LIREDONNEESTABCROISDYNAMIQUE renvoient autre chose que les valeurs par défaut, et passer l'ordre des onglets à `removeSheetInFormula` pour le raccourcissement des références 3D.
- Insertion/suppression : `[@Col]` hors du tableau n'est pas réécrit.
